# Источники демонстрационных изображений

Текущие изображения — AI-обработанные версии пяти кадров, присланных пользователем в чате. Обработка выполнена встроенным инструментом imagegen по поручению пользователя улучшить качество и использовать подборку на сайте. Это обработанные версии, а не исходные файлы. Наличие изображения не подтверждает авторство AUREN.

- user-forest.png — дом в лесу с тёплым интерьерным освещением; исходная авторская маркировка сохранена.
- user-interior.png — гостиная с панорамным изогнутым остеклением.
- user-concrete.png — бетонный минималистичный дом вечером.
- user-stone.png — тёмный каменный дом с широкими скатами крыши.
- user-manor.png — резиденция в вечернем свете.
- user-hero-pines.png — обработанная версия нового присланного кадра: дом среди сосен; используется под главным заголовком.
- user-project-flat.png — обработанная версия второго нового присланного кадра: фасад со ступенями; используется первым в портфолио и в соответствующем кейсе. Авторская маркировка сохранена.
- studio-team-landscape.png — обработанная версия присланного пользователем снимка людей за столом, повёрнутая на 90° по часовой стрелке встроенным imagegen. Используется фоном секции студии; затемнение добавлено через CSS, не в файл.
